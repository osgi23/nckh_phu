# 🟠 Các phương pháp so sánh

`dp_pso_pfcm.py` (A3), `dp_sca_pfcm.py` (A4), `dp_fbi_pfcm.py` (A5) đã chạy được. Runner còn đưa DP-PFCM (A1) và mô hình chính DP-GA-PFCM (A2) vào đúng giai đoạn 2.

`ga_ifwcom.py` (A6) và `sca_fpcom.py` (A7) hiện là giao diện báo thiếu nguồn, **chưa có thuật toán**. Không tính hai file này vào số mô hình đã triển khai; các số trong báo cáo chỉ lấy từ Table 11–13 của bài chính.

Từ thư mục dự án: `python code/orange_comparisons/run.py --profile quick --color always`.

Bỏ `--profile quick` để chạy 30 lần. Thêm `--require-all` để dừng nếu thiếu bất kỳ phương pháp nào trong bài. Tham số và giới hạn: [ASSUMPTIONS.md](../ASSUMPTIONS.md).
