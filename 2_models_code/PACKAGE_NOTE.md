# Nội dung gói tải về

output/code/DP_GA_PFCM_code.zip chứa thư mục code với các script, requirements, cấu hình, tài liệu, bảng màu, **14 dataset CSV đã chuẩn bị cùng metadata**, và kết quả chạy thật.

Không đóng gói code/.venv vì virtual environment phụ thuộc vị trí và Python trên máy. Tạo môi trường mới và cài requirements.txt theo README_REPRODUCTION.md. Raw ZIP/tệp tải nguồn cũng không nằm trong gói để giảm kích thước; chạy download_datasets.py để lấy lại raw cache đầy đủ. SHA nguồn đã tải vẫn được ghi trong metadata.

Mở code/FILE_GROUPS.html để nhận ra nhóm file theo màu, ASSUMPTIONS.md để biết tham số tự chọn và VALIDATION.md để xem mức độ khớp kết quả. Hai file GA-IFWCOM/SCA-FPCOM là giao diện báo thiếu nguồn, chưa có thuật toán; không coi gói này là tái tạo đầy đủ cả 11 phương pháp hay code gốc.
